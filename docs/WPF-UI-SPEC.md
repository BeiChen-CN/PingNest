# PingNest WPF 版 · 桌面 UI 完整设计规范（优化版）

> 项目背景：PingNest 是本地优先的 Windows 桌面效率工具，通过 **Windows UI Automation（UIA）** 监听微信 4.x 会话列表变化，提供自定义悬浮通知、通知历史、搜索、关键词静音、暂停/恢复监听。非聊天软件，不模仿微信主界面。
>
> 技术栈（本规范配套）：C# + .NET 8 + WPF + MVVM（CommunityToolkit.Mvvm）、SQLite 本地存储、UIAutomationClient 监听、无边框窗口 + WindowChrome。

---

## 一、产品定位（不变，重申约束）

- 安静、可靠、**本地优先**：所有通知内容仅保存在本机 SQLite，无任何网络上传。
- 监听微信会话列表变化（UIA），**不注入、不改写微信**，不展示聊天正文之外的会话内容。
- 界面是「状态与历史管理面板」：告知用户"谁来了、什么时候、是否已静音、是否需要处理"。
- **禁止**：聊天窗口布局、会话气泡、微信配色、表情包、霓虹灯、大面积渐变、装饰性插画。

## 二、技术约束（优化新增）

| 项 | 约束 |
|---|---|
| 框架 | .NET 8 (LTS) + WPF，XAML 全部走 ResourceDictionary |
| 架构 | MVVM（CommunityToolkit.Mvvm），页面/窗口/控件三层的命令与可观察状态 |
| 窗口 | WindowChrome 自定义标题栏；支持 125%/150% DPI 缩放；最小 960×640，默认 1180×760 |
| 图标 | **Segoe Fluent Icons 字体**（Windows 11 自带， 起），禁止 Emoji/手绘风 |
| 存储 | SQLite（Microsoft.Data.Sqlite）：通知历史表、静音规则表、设置表；写入走异步队列 |
| 监听 | UIAutomationClient 监听微信主窗口会话列表（ListView/ListViewItem 结构变化），断开自动重连，状态可见 |
| 动画 | Storyboard 160–220ms；进入 ease-out、退出 ease-in；尊重系统"减少动态效果"（取消动画） |
| 可访问性 | 所有交互控件具备悬停/按下/禁用/键盘焦点态；AutomationProperties.Name 齐全；支持键盘完整操作 |

## 三、颜色系统（严格使用，绿色克制）

| Token | 色值 | 用途 |
|---|---|---|
| AppBackground | #F6F8F7 | 窗口/页面背景 |
| ContentBackground | #FFFFFF | 卡片、面板、输入区 |
| SelectGreen | #E8F7EE | 选中项/激活导航背景 |
| HoverGreen | #F0FAF4 | 悬停背景 |
| ActionGreen | #20A866 | 主按钮、开关、运行状态点、选中描边 |
| TextPrimary | #18211D | 正文 |
| TextSecondary | #66736C | 说明文字、时间戳、元信息 |
| BorderWeak | #E3EAE6 | 卡片/分割线/输入框边框 |
| WarnAmber | #D98B27 | 警告、静音状态点缀 |
| ErrorRed | #D9534F | 错误、清除危险操作 |

规则：
- 绿色**只出现**在：连接/监听/运行状态点、选中项背景、ToggleSwitch 开启态、主操作按钮、焦点描边。
- 页面主体是白/浅灰，**禁止大面积绿色填充**与渐变（状态点允许极轻微光晕，不使用投影扩散）。

## 四、排版与几何

- 字体：主字体 `Segoe UI Variable`，中文回退 `Microsoft YaHei UI`，数字用 `Segoe UI Variable Display` 的 tabular-nums。
- 字号：页面标题 22/600；区块标题 15–16/600；正文 13–14/400；辅助信息 12；徽标 11/600。
- 圆角：卡片 12，按钮/输入框/下拉 8，状态徽标圆形，通知预览 14。
- 阴影：仅 `0 4px 16px rgba(21,45,32,0.06)`；悬浮可提升到 0 8px 24px 同色系 0.10；**禁止重阴影**。
- 间距：4px 基数；主内容区外边距 24px，区块间距 16px；列表行高约 60px（历史页可 48px 高密度）。
- 不使用嵌套卡片、超大标题、Hero 图。

## 五、窗口与导航

- 默认 1180×760，最小 960×640；可缩放、高 DPI。
- **自定义标题栏**（高度约 40px）：左侧应用图标（16px）+ 名称"PingNest"；中部右侧放微信连接状态胶囊（绿点=已连接 / 灰点=未连接，点击跳转概览）；右侧窗口控制按钮（最小化/最大化/关闭，44×32 热区）。
- **左侧 72px 图标导航栏**：图标 + 下方极短文字（两字以内）。当前项使用 SelectGreen 圆角背景（图标仍深色，不反白）。项：概览、历史、静音规则、通知外观、设置。
- 导航栏底部固定两个低调入口："本地隐私"（打开隐私说明对话框）、"关于"。
- 导航切换无滑动动画，仅 160ms 淡入 + 选中态过渡。

## 六、页面规格

### 6.1 概览（Dashboard）
- 顶部：标题"通知伴侣"22px；右侧主操作按钮 **暂停监听**（暂停后变为 **恢复监听**，状态点同色变化）+ "更多"菜单（立即检查、打开历史、退出到托盘）。
- 第一行三个**紧凑状态区块**（不是大卡片）：圆点 + 短标签 + 数值。
  1. 微信连接（已连接/未连接/检测中）
  2. 监听运行（运行中/已暂停/自动恢复中）
  3. 今日通知（数字 + "条"）
- 中部"最近通知"列表（行高 60px）：头像占位（圆形 36px，无头像时首字符）、会话名（13/600）、消息摘要（12，单行省略）、相对时间（12 次级色）、未读紧凑圆形徽标、静音状态小图标（WarnAmber）。行悬停 HoverGreen，选中 SelectGreen。
- 右侧窄状态面板（约 240px）：UI Automation 状态（附加进程名/句柄）、最后检测时间、自动恢复状态与倒计时、监听源（微信会话列表）摘要。
- 底部隐私说明："所有通知内容仅保存在本机"（12px 次级色，左对齐）。

### 6.2 通知历史
- 顶部工具栏：搜索框（带图标，可清除）、日期范围筛选（下拉）、会话筛选（下拉）、右侧"更多"菜单含"清空历史"（**必须确认对话框**：说明删除条数，错误色按钮"清空"，次级按钮"取消"）。
- 高密度列表（行高 48px）：时间（等宽数字）、会话名、摘要（单行省略）、来源类型（私聊/群聊）、静音标记。支持按时间/会话排序（点击表头）。
- 选中行 → 右侧详情面板（滑出 240ms）：完整摘要（两行）、完整时间、会话、类型、静音状态、操作（标记已读/复制摘要/删除该条）。
- 空状态：线性图标（如文档图标）+ 一句说明（"暂无通知记录，收到微信消息后会显示在这里"），无插画。

### 6.3 静音规则
- 紧凑规则表格（表头 + 行，行高 44px）：关键词、匹配方式（包含/精确/正则）、启用状态（ToggleSwitch）、命中次数、更多菜单（编辑/删除）。
- 右上角"新增规则"主按钮。
- 新增/编辑用**右侧滑出面板**（320px，240ms）：关键词输入、匹配方式下拉、备注输入、启用开关；底部"保存/取消"。
- 删除进"更多"菜单，删除后 200ms 行淡出；删除确认可省略（规则可重建），但需在面板显示 toast 提示。
- 规则即时生效，不影响已产生的历史记录。

### 6.4 通知外观
- 左列设置区（约 380px，分组区块）：
  - 通知位置：九宫格选择器（不是下拉）+ 多显示器下拉
  - 停留时间：滑杆 3–15s
  - 透明度：滑杆 70–100%
  - 是否显示摘要：ToggleSwitch
  - 点击行为：下拉（打开微信并聚焦会话 / 打开历史 / 无操作）
- 右列**实时预览**：白色圆角面板（圆角 14、轻阴影、淡绿状态线 3px 顶部），清晰头像 + 两级文字（会话名 14/600 + 摘要 12 次级）。预览随设置即时变化，可拖动位置测试。
- 明确不是 Windows Toast：自定义窗口渲染，跟随 Win11 圆角。

### 6.5 设置
- 分组区块（不用嵌套卡片）：启动与托盘（开机自启 ToggleSwitch、关闭到托盘、显示托盘提示）、监听（UIA 重试间隔、自动恢复开关与等待秒数）、历史（保留天数、自动清理开关、立即清理按钮）、数据与隐私（导出 JSON、清空全部数据——确认对话框）、关于（版本、检查更新占位）。

## 七、通知弹窗（悬浮通知本体）

- 独立无边框置顶窗口（tool window），圆角 14、轻阴影、可点击、可关闭、自动消失。
- 结构：顶部 3px 淡绿状态线 + 头像 + 会话名 + 相对时间；正文两行摘要（可设置隐藏）；右下角静音/暂停角标。
- 连续消息同会话合并：同一窗口叠加计数徽标，不叠加新窗口。
- 动画：160–200ms 滑入 + 淡入；退出 120ms 淡出；尊重减少动画。
- 多显示器：记忆上次所在显示器；暂停监听期间不弹窗（通知进入历史）。

## 八、交互与状态细节

- 暂停监听：全局按钮 + 托盘菜单；暂停期间新通知只入库不弹窗；恢复后状态点回绿。
- 自动恢复：UIA 断开超过阈值自动重启监听，倒计时在概览面板可见；连续失败 3 次转"检测中"并要求手动干预（提示文案克制）。
- 键盘焦点：Tab 顺序遵循阅读顺序；焦点环使用 ActionGreen 1px 圆角描边；所有按钮可 Enter/Space 触发。
- 禁用态：控件 45% 不透明度 + 禁用光标；工具提示解释原因（如"需要先连接微信"）。
- 空/错误状态：全部用线性图标 + 一句 13px 次级文字，无插画、无红色警告横幅（仅内联提示）。
